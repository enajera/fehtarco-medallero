🎯 KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ Smart Duplicate Detection
   → Automatically skips records that already exist
   → No error thrown - just increments "skipped" counter
   → Safe to re-import same data

🔗 Foreign Key Resolution
   → Resolves "Club Name" string → club ID
   → Resolves category by bowType + gender + division
   → Resolves athlete by firstName + lastName
   → Resolves event by event name
   → Returns clear error if reference not found

⚠️  Item-Level Error Handling
   → Import continues even if some items fail
   → Each error includes item index and reason
   → Response shows: { inserted: N, skipped: M, errors: [...] }

✅ Full Validation with Zod
   → Schema validation for all fields
   → Type checking (enums, strings, numbers, dates)
   → Custom error messages
   → Returns 400 with detailed validation errors

🔐 Security
   → Requires JWT token in Authorization header
   → Requires ADMIN or SUPER_ADMIN role
   → All inputs validated before database access
   → Safe error messages (no stack traces in production)

🏗️  Clean Architecture
   → Separation of concerns (routes → controllers → services → DB)
   → Reusable service layer
   → Testable components
   → Easy to extend
